Bookglow Volumes I–VI

A design-first, in-place retrofit blueprint for the current Bookglow monorepo. It redesigns UI, UX, layout, responsive structure and components while keeping all existing Firebase, Firestore and business logic untouched.

Programme rule: the current project and current live components are the target. No parallel implementation, backend migration or logic rewrite belongs in these six volumes.
Future boundary: Firestore-to-Supabase migration and Firebase removal will be planned only after the entire design programme is complete, as a separate final-stage blueprint.
